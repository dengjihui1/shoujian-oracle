# 守简 0.28.0 全方位评估与升级记录

评估日期：2026-09-23。范围是独立开源教学项目 `shoujian-oracle`，不是主项目的商业占卜、住宅风水、支付或账号系统。0.27.0 的历史实测见 `QUALITY_BASELINE.md`；这里仅写本轮复核所得，不把旧版或模拟数据当作本轮真实服务成绩。

## 产品判断

当前的差异点是“可自由交谈的中式虚拟卦师 + 用户明确选择的三钱六爻 + 可回查的经传证据”。它已不是固定问答演示，但仍是有限知识范围的开源组件，不是能给所有风水、八字和现实决策下确定结论的师傅，也不能因自动测试通过就称为可收费生产版。

| 维度 | 当前已具备 | 本轮确认的缺口或边界 |
| --- | --- | --- |
| 自由问答与记忆 | 普通问题走模型流式回答；本机保留最近已完成轮次；时间由服务端提供 | 模型回答质量受外部供应商影响；本轮未做系统性的真人盲评 |
| 经传 RAG | 64 卦、384 爻、8 个《说卦》片段；库外普通问题自然转自由回答 | 白名单引用校验能防伪编号，但不能自动证明一句话的全部语义都由证据支持；现代风水和八字不在此库 |
| 起卦 | 情境访谈、可编辑摘要、六爻纯函数和只读卦象上下文 | 用户仍可自主提供六爻值；该组件不证明“超自然准确性”，也没有八字历法引擎 |
| 语音 | 浏览器增量识别优先，录音兜底；句级 TTS 预取、打断和失败降级 | 真实麦克风、噪声、回声、浏览器音色与云端首声 P50/P95 未验收；不是全双工 |
| 虚拟人 | 有听、想、说、打断等状态与轻量动作 | 2.5D 表现仍偏轻；缺真人用户对声音、节奏和人物可信度的测评 |
| 公开部署 | HTTPS/Redis/探针/脱敏日志配置与 CI 门禁 | 正式域名、外部监控、真实供应商额度和收费权益系统未验收 |

## 本轮已修复

1. **首声时间与人物状态虚高**：以前句子进入播放器前就报 `playing`。现在等浏览器朗读 `onstart`、Web Audio 启动或媒体元素 `playing` 后才切换；本机朗读 5 秒未启动会取消并报可恢复错误，文字聊天不受影响。新增“未开始”“迟到开声”“取消后不得复活”回归。这里的“首声”是播放器开始事件，不是麦克风测得的真实扬声器声学延迟。
2. **请求伪造卦象字段**：服务端以前信任客户端的卦名、动爻与变卦展示值。现在只接收六个合法爻值并调用同一纯函数重算；缺失或非法爻值返回 400。该修复保障六爻与解读上下文一致，但无法证明用户是否真的随机掷钱。
3. **无证据却让模型解释经传**：明确的经传问题或带实际卦象的解卦请求，若检索为空，直接给自然的“本轮资料不足”说明，不让模型在零证据条件下补造出处。库外普通问答仍继续走自由模型。

## 本轮可重复检查

- `npm test`：207 / 207 通过。
- `npm run eval:rag`：固定集 recall@4 与域外负例精度均 100%；均值 3.24 ms，P95 5.27 ms。该数字仅是本机 15 条检索案例，**不是**模型回答准确率。
- `npm run check` 与 `git diff --check`：通过。
- Playwright：Chromium、WebKit、Pixel 7 与 iPhone 14 仿真共 24 / 24 通过。Firefox 本机 6 条在 `browserType.launch` 出现 Windows `spawn UNKNOWN`，单 worker 重跑仍然无法启动；没有执行到产品逻辑，因此本机 Firefox 状态为**未验收**，不能记为产品通过或产品失败。远端 CI 需另行复核。
- 启用开发机现有 Gemini 配置后的最小真实抽样：身份问答正常，`gemini-3.1-flash-lite` 总耗时 3564 ms；“乾卦初九爻辞”返回实际检索到的 `ZY-01-LINE-1`，但非流式 `/api/chat` 总耗时 28176 ms。两次样本不足以给出 P50/P95，也不代表浏览器 SSE 的首字耗时；经传回答仍需要缩短和人工核对语义贴合度。

## 下一轮按优先级验收

1. **P0 真实设备语音**：至少在 Windows Chrome/Edge 与一部手机上，各完成 10 轮语音、3 轮连续对话、一次打断和一次 TTS 失败；导出延迟报告并核对真实首声 P50/P95。拿不到麦克风或 Cloud 凭证时不声称通过。
2. **P0 模型回答质量**：建立包含普通聊天、身份、日期、经传原文、卦后追问、库外问题、医疗/投资仅供参考与危机求助的人工评测集，记录事实性、引用贴合度、自然度和失败恢复；真实 Gemini 抽测与模拟契约分开。
3. **P1 语音供应商决策**：真实比较本地语音、Gemini TTS 和获凭证后的 Google Cloud TTS 的新句首声、失败率、音色与单轮成本。当前缓存命中毫秒级不能代表新句可实时开声。
4. **P1 人物表现**：在真实语音节奏上评估老卦师口吻、动作幅度、闭口时机和减少动态模式，再决定是否升级人物素材。不要为了更“神”牺牲可交流性或制造算命准确性的错觉。
5. **P1 公开服务安全**：账号权益、按次配额、供应商成本上限、滥用监控、域名与证书、告知和退款流程属于商业主项目或独立运营层；不要直接混进这个 MIT 教学组件。

可接受的当前结论：源码及主要交互链路可作为开源演示继续发布；**尚不能据此宣称真实语音、Google Cloud 速度、Firefox 本机或公众收费上线全部完成。**
