# 守简 0.35.0 第八轮自检

本轮检查服务端 POST 请求体边界。此前 `/api/speech` 与 `/api/transcribe` 收到合法 JSON 的 `null` 或数组时，会在读取属性时抛出异常并返回 500。现在共用解析器要求顶层为 JSON 对象；原始值与数组一律返回可预期的 400 `invalid_json_body`，且不会调用云端供应商。

三个 POST API 均补充 `null`、`[]`、`42` 的回归测试。本地 `npm test` 221 / 221、Chromium / WebKit 及两组移动仿真 44 / 44 通过；固定 RAG 集 recall@4 与域外负例精度均为 100%，项目检查、空白符检查和生产依赖审计通过。此轮仅验证服务端输入边界；真人回答质量、真实设备语音和部署体验仍需单独验收。
