## 四、当前可接受标准

以下条件同时满足时，当前版本可作为 GitHub 开源教学项目发布：

- 104 项测试、项目体检和空白符检查全部通过；
- 无密钥时仍可本地起卦，有密钥时自由聊天、RAG、流式文字和 TTS 契约可用；
- 生意、投资、医疗、法律、感情等主题可以起卦但不输出专业指令或保证结果；即时人身危险会转现实危机支持；
- 经传回答有白名单来源，未知内容不伪造引用；
- 密钥不进入浏览器、仓库或错误响应；
- 回答成功、断流、主动停止和配额失败后都不会锁死输入；最终失败提供用户触发的重试入口。

## 五、仍未覆盖的生产风险

这些不阻塞本地开源版，但在面向公众收费或长期托管前必须处理：

- 未完成 Chrome、Edge、Safari 和移动端的自动化浏览器矩阵；
- 麦克风权限、噪声环境和不同设备录音延迟仍需用户设备实测；
- 当前内存限流不支持多实例，生产环境需要共享限流、成本配额和滥用防护；
- 需要正式 HTTPS、反向代理、健康检查、结构化脱敏日志和供应商故障监控；
- Gemini 免费额度、区域可用性和 TTS 预览模型容量会变化；
- 当前真实聊天总耗时受模型和网络影响，已做流式展示与首句 TTS 预取，但仍应继续记录 P50 / P95。
