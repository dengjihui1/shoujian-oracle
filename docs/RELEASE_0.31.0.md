# 守简 0.31.0 第四轮自检

这轮聚焦语音输入的两个竞态，不改变经传数据、起卦算法或云端 API 选择。

## 已修复

1. 浏览器语音识别可能再次上报已完成片段。旧实现从 `resultIndex` 起把 final 文字追加到旧字符串，导致用户原话重复。现在每次从完整 `event.results` 快照重建 final 与 interim；识别结束后的迟到回调也不再更新文字。
2. 录音授权弹窗未返回时，连续点击可能并发申请麦克风并覆盖前一个流。录音器和页面编排层都阻止重复启动；页面离开后才获授权时，立即停止并释放迟到的录音。

## 验证

- `npm test`：216 / 216 通过；包含重复 final 片段和录音授权并发的单测。
- 本机 Playwright：Chromium、WebKit 与两组移动仿真共 36 / 36 通过；新增两条浏览器流程分别检查只送问一次、离开页面后释放录音。测试使用假识别器/录音器，不等于真实麦克风验收。
- `npm run check` 与 `git diff --check` 通过；固定 RAG 集 recall@4、域外负例精度均 100%。该指标只覆盖检索。
- Firefox 本机运行环境此前存在 SideBySide 错误；本轮未把其他引擎结果当作 Firefox 验收。推送后的 GitHub CI 状态须按本版本提交单独核对。
