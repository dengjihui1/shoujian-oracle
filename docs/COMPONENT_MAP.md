# 组件抽取与流程图

## 一、产品流程

```text
用户进入
  ↓
墨衡迎客（虚拟人主持）
  ↓
用户键入或用麦克风提交一个问题
  ↓（可选云端）
Gemini Transcribe：短录音 → 可编辑文字
  ↓
问题边界检查 ── blocked → 墨衡说明为什么不能起卦
  │              rewrite → 引导缩成一件可观察的小事
  ↓ clear
固定当前原问
  ↓
浏览器本机三钱六掷
  ↓
纯计算层：六爻 → 上下卦 → 64卦 → 动爻 → 之卦
  ↓
墨衡给出克制的结构提示
  ↓
Gemini 已配置 → 自由追问 + 可选 TTS 语音回答
Gemini 未配置 → 有限追问：意思 / 动爻 / 算法 / 边界
```

## 二、运行时组件

| 组件 | 文件 | 输入 | 输出 | 是否纯函数 |
| --- | --- | --- | --- | --- |
| 虚拟人外壳 | `src/shoujian-oracle.js` | 点击、文本、会话状态 | 对话和卦象界面 | 否，负责 UI 状态 |
| 对话路由 | `src/dialogue-engine.js` | 用户追问、当前卦象 | 固定意图与回答 | 是 |
| 问题边界 | `src/question-boundary.js` | 原问文本 | `clear/rewrite/blocked` | 是 |
| 起卦计算 | `src/oracle-engine.js` | 六个 6/7/8/9 | 本卦、动爻、之卦、审计轨迹 | 是 |
| 随机适配器 | `castWithCoins()` | `crypto.getRandomValues` | 六个爻值 | 外层有随机，排卦仍纯计算 |
| 浏览器 API 适配器 | `src/api-client.js` | 文本、录音 | JSON | 否，网络 I/O |
| 录音与播放 | `src/audio-recorder.js` / `audio-player.js` | 麦克风、PCM | 音频 Blob / WAV | 播放有 I/O，WAV 包装为纯函数 |
| 本机 API 服务 | `server/index.mjs` | `/api/*` 请求 | 脱敏后的稳定响应 | 否，网络 I/O |
| Gemini 适配器 | `server/gemini-client.mjs` | 只读卦象、文本、音频 | 转写、回答、PCM | 否，可注入假 `fetch` 测试 |

## 三、会话状态机

```text
question --问题通过--> ready --起卦--> reading
   ↑                       │              │
   └────问题需重写─────────┘              ├──追问→ reading
   └──────────────另起一问────────────────┘
```

- `question`：可以提交原问，运行边界检查；
- `ready`：原问已经固定，只允许起卦或重置，防止起卦前后偷偷换题；
- `reading`：展示结果并允许有限追问；
- 所有状态只在当前页面内存中，不写入浏览器存储；启用云端后，主动提交的必要内容会发给 Google Gemini。

## 四、抽取边界

### 已抽取

- 墨衡式主持语气和阶段仪态；
- “为什么／来源／边界”的受限问答思想；
- 起卦前公开问题边界；
- 三钱爻值、八卦、64 卦和变卦计算。

### 没有抽取

- 户型、罗盘、命卦、家具方位和住宅规则；
- 周易古籍全文、卦辞、爻辞与说卦知识库；
- 纳甲、卦宫、世应、干支、六亲、旬空和六神；
- 问契哈希、私印、验期、追验、案卷与跨设备迁移；
- 账户、商品、支付、退款和权益；
- 主项目虚拟人高清素材、知识库、档案和商业语音系统。

这些边界保证本仓库足以学习“虚拟人 + 特殊工具”的组合方式，又不是商业核心的开源副本。
