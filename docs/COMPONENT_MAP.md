# 组件抽取与流程图

## 一、产品流程

```text
用户进入
  ↓
墨衡迎客（虚拟人主持）
  ↓
用户键入或用麦克风提交一个问题
  ↓（可选云端，携带最多 16 条且约 6000 字符的最近上下文）
浏览器实时 ASR：增量语音 → 可编辑文字
  └── 不支持时：Gemini 内联音频 → Files API 兜底
  ├── 显式开启实时语音对话 → 定稿 / 停顿自动提交 → 回答与朗读期间暂停收音 → 自动恢复倾听
  │                              └── 打断并说话 → 取消旧回答 / TTS / 播放 → 立即重新倾听
  ├── 直接问墨衡 → 弱相关检索清空后普通回答；经传问题走冻结知识检索与一次引用修复
  └── 以此问起卦
  ↓
问题边界检查 ── blocked → 即时人身危险：停止起卦并给现实危机支持
  │              advisory → 允许起卦并附领域参考说明
  ↓ clear / advisory
情境访谈：按原问缺项追问 2–4 项，可跳过或提前整理
  ↓
可编辑问卦摘要 → 用户确认后冻结
  ↓
浏览器本机三钱六掷
  ↓
纯计算层：六爻 → 上下卦 → 64卦 → 动爻 → 之卦
  ↓
本卦、实际动爻、之卦与上下卦强制进入知识检索
  ↓
Gemini 已配置 → 按场景模型路由 → SSE 流式自由追问 + 字符级显示 + 中途断流恢复 + 来源展开
  ├── 首字前失败：可选 OpenAI-compatible 供应商回退 + 短时熔断
  └── 可选语音：完整句切分 → 极速浏览器朗读，或云端 TTS 预取 / 合并 / 缓存 → 顺序播放 → 墨衡嘴型
Gemini 未配置 → 有限追问：意思 / 动爻 / 算法 / 边界
```

## 三、会话状态机

```text
question --clear / advisory--> intake --确认摘要--> ready --起卦--> reading
   ↑                       │              │
   └──即时人身危险：危机支持───────────────┤
   └──────────────另起一问────────────────┘
```

- `question`：可以自由闲聊、问身份与一般基础问题、问经传知识，或明确选择把当前文字作为起卦原问；
- `intake`：只补问原问缺失的观察时间、可选路径、已知事实、现实约束或判断标准；可跳过、提前整理，不索取生辰八字；
- `ready`：可编辑摘要已经由用户确认并冻结，只允许起卦或重置，防止起卦前后偷偷换题；
- `reading`：展示结果并允许自由追问；涉及本卦、动爻、之卦或原问时，检索层强制优先纳入当前卦证据；身份、时间、基础概念以及明确点名其他卦 /《说卦》的问题不会被旧卦强绑；
- 最近 24 条已完成对话、阶段、原问和六爻快照写入当前浏览器 `localStorage`；刷新后由纯计算层从六爻重建同一卦，并可手动清除。错误、取消、未完成回答及没有有效回答的孤立问题不会进入后续上下文。每次云端请求最多发送最近 16 条、约 6000 字符、只读卦象和本轮检索片段；服务端不建用户档案。
- 导出会生成 `shoujian.oracle-session` v1 JSON；导入限制为 256 KiB，并重新执行消息、阶段、访谈和六爻清洗。文件由浏览器直接下载和读取，不经过项目服务器。
- 实时语音对话是独立外围状态机：只有点击带“自动发送”的入口才启用；听清后停止识别再提交，回答与朗读期间不收音；打断会淘汰旧请求和音频再重开识别。文字会话状态和卦象状态不因此改变。

## 四、抽取边界

### 已抽取

- 墨衡式主持语气和阶段仪态；
- “为什么／来源／边界”的受限问答思想；
- 起卦前公开问题边界；
- 三钱爻值、八卦、64 卦和变卦计算。
- 独立公开来源的《周易》《彖》《象》《说卦》冻结数据、检索器、引用白名单与来源展示。

### 没有抽取

- 户型、罗盘、命卦、家具方位和住宅规则；
- 纳甲、卦宫、世应、干支、六亲、旬空和六神；
- 问契哈希、私印、验期、追验、案卷与跨设备迁移；
- 账户、商品、支付、退款和权益；
- 主项目住宅知识、虚拟人高清素材、档案和商业语音系统。

这些边界保证本仓库足以学习“虚拟人 + 确定性起卦 + RAG 知识问答”的组合方式，又不是商业核心的开源副本。

虚拟人参考项目、未采用 Live2D／VRM 的原因和人物资产边界见 [虚拟人研究与实现说明](VIRTUAL_HUMAN_RESEARCH.md)。

每个文件的职责、输入输出、依赖、失败降级、对应测试、成熟度和练习入口见 [守简模块池](MODULE_POOL.md)。
