# 0.56.0：问心空间与交互重构

本轮由主实现与 Astra 独立审查共同推进，重点解决首屏工具堆叠、入口可访问性与操作状态丢失。Google Cloud 账号开通仍按用户要求后置。

## 体验变化

- 用单一中央对话空间替换大人物与聊天框的左右面板；月色、山水、印章及书法标题构成入口，人物保留为对话主持头像。
- 统一样式提取至 `src/courtyard-styles.js`，移除旧主题和覆盖主题两套重复规则。
- 提供三个问题灵感，只填入草稿，不自动发送；聊天为主要动作，起卦必须明确选择。本地 Enter 也不会隐式起卦。
- 语音设置、单次录音和性能指标进入折叠区；自动语音、错误提示及停止回答仍在操作主线上。
- 理问、确认、解意有三步进度。确认后不再显示无用的禁用输入框；可以直接整理摘要，保留手动补充的路径。
- 结果先展示白话提醒，六爻结构按需展开；修正相同上下卦带来的重复建议，条件式文案不暗示现实事实已被核实。
- 命名折叠区、输入光标和选区随重渲染恢复。
- 开场等待用户进入，支持跳过、Escape、Tab 循环、背景 inert 和焦点恢复；支持重播且保留会话。收音、转写、回答或自动语音活跃时禁止重播。
- 减少动态效果直接进入；门页开启期间检查动态偏好，兼容 WebKit 媒体事件未送达时的清理。

## 验证与修复记录

- 262 项 Node 单元测试通过，项目结构与敏感内容检查通过。
- 桌面 Chromium、WebKit 与两组手机仿真的首轮 116 项浏览器测试：109 通过、3 个按平台范围跳过、4 个失败。
- 根据失败修复手机横向溢出、欢迎态误藏录音错误、WebKit 动态减少动画时门页未解除的问题；增加媒体事件丢失回归。覆盖失败项及门页的 32 项定向复验全部通过。
- 新测试覆盖 360px/390px 输入首屏可见与无横向溢出、灵感不自动发送、折叠状态和输入选区保留、本地聊天不隐式起卦及完整短路径起卦。
- 本机 8001 真实 Gemini 对话与起卦解说完成，输入可恢复；浏览器检查桌面布局和手机操作区。

## 验证边界

本机 Firefox 仍在启动阶段报 `spawn UNKNOWN`，不计为本机通过。浏览器仿真不等于真机验收；Google Cloud 流式识别没有真实账号验证。上述结果不宣称生产上线或所有语音环境均已验收。
