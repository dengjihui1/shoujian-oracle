审计日期：2026-09-27。用户已确认：独立网站／手机网页，月预算不超过人民币 300 元，先做小规模验证。当前不包含收费、应用商店、小程序或数字人视频服务。

### 生产探针和接口的解释

```bash
docker compose --env-file deploy/compose.env -f deploy/compose.yml ps
curl -fsS https://你的域名/healthz
curl -fsS https://你的域名/readyz
```

若网关已启用认证，使用受控的认证会话执行，不把密码写入可共享命令。`/api/status` 返回的模型名是配置值；模型可用性必须通过真实请求验证。不要使用会产生模型调用的 API 作为频繁健康探针。

### 隐私验收特别注意

- 服务端不建持久用户档案，不等于数据从未到达服务端或第三方。
- `server/speech-cache.mjs` 当前会缓存生成音频，默认 TTL 30 分钟、最多 48 项／24 MiB；这是服务端内存缓存，须在隐私描述中与“本机对话记录”区分。删除本机记录不自动证明第三方或内存缓存同步删除。
- 浏览器 `SpeechRecognition` 可能使用浏览器供应商的在线识别，不能宣传为必定离线。打开浏览器语音不需要项目 Key，不等于没有第三方处理。
- 生辰原始日期/时刻只在本页内存，刷新清除，不随本机会话持久化；独立勾选同意后，仅四柱符号与历法约定用于后续 AI 请求。四柱本身仍是个人信息；生成的解说会进入本机聊天记录，关闭同意或清除生辰不撤回已经发出的请求，也不自动删除既有解说。
- 生辰采用 `lunar-javascript` 1.7.7（MIT），北京时间、立春换年、节气换月、午夜换日；未知时刻/节气交界会标待定。未校正真太阳时及历史夏令时。现有知识库是周易经传，不是八字古籍库。
