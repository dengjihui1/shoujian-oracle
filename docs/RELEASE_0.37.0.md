# 守简 0.37.0 第十轮自检

本轮复查经传问答的流式引用边界。此前第一稿即使没有有效引用，也会先经 `delta` 显示，并可能进入朗读队列；最终修复回答虽会替换页面文本，却不能收回用户已经看到或听到的草稿。

现在含检索证据的回答先在服务端收齐并核验引用，再向页面发送可显示、可朗读的文本。首稿无效时，修复后的文本仍通过 `replace` 发出；普通闲聊仍逐段流式返回。回归测试覆盖无效草稿不触达前端回调、有效引用完整释放。经传问答的首次显示时间因此会增加到引用核验完成，属于明确的体验代价。

本地 `npm test` 223 / 223、Chromium / WebKit 及两组移动仿真 44 / 44 通过；固定 RAG 集 recall@4 与域外负例精度均为 100%，项目检查、空白符检查和生产依赖审计通过。当前核验只检查引用 ID 是否来自本轮检索，不能证明解释在语义上忠于经文；仍需人工抽审真实模型回答和真实设备语音。
