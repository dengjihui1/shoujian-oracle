## 下载与运行

下载附件 `shoujian-oracle-v0.57.1.zip`，解压进入 `shoujian-oracle`：

```bash
npm ci
npm start
```

需要 Node.js 24+。打开 `http://127.0.0.1:8000/`。无密钥时可体验本地起卦、生辰参照和界面；AI 对话需按仓库 API 文档自行填写服务端配置。
