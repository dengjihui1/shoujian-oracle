# 守简 0.39.0 第十二轮自检

生产审计发现模型及兼容供应商的 SSE 解析器没有单事件大小上限，服务端也没有单轮回答长度上限。异常上游可持续扩大缓冲和回答文本；长文本还会继续进入页面与朗读队列。

现在单个 SSE 事件限制为 64 KiB 字符，单个网络块限制为 256 KiB 字节，单轮回答限制为 16 KiB 字符。流式超限会取消上游并返回 `response_too_large`，非流式回答也拒绝超限结果。回归覆盖两类供应商解析器和两种聊天 API。阈值是当前组件的资源保护上界，不是模型质量指标。

本地 `npm test` 229 / 229、Chromium / WebKit 及两组移动仿真 44 / 44 通过；固定 RAG 集 recall@4 与域外负例精度均为 100%，项目检查、空白符检查和生产依赖审计通过。企业级生产审查的其余模块、证据和缺口持续记录于 [生产审计台账](PRODUCTION_AUDIT_2026-09-24.md)。
