# 0.57.1：真实页面回归发现的繁简检索漏召回

在 0.57.0 推送后继续测试真实页面，发现简体“自强不息”未召回知识库中繁体“自強不息”，触发资料不足回复。原因是原有手工字表没有覆盖“強”，旧固定评测集未覆盖该常见问法。

修复：服务端使用固定版本 `opencc-js@1.4.2` 的繁转简模块，替换不完整的手工映射；只有检索索引和问题归一化，显示给用户的古籍、出处及原文保持原样。保留古字“遯/遁”的检索别名。该依赖仅在服务端，不增加浏览器首屏下载。

新增简体/繁体“自强不息”“厚德载物”“亢龙有悔”成对回归，以及固定 RAG 集中的两条真实短句问法。

验证：283/283 Node 测试通过；RAG 扩展集 recall@4、负例精度均 100%，平均 3.25 ms、P95 9.29 ms；结构检查通过。浏览器端未变更，0.57.0 四项目 129 通过/3 跳过和后补 16 项回归仍是对应前端证据；本次提交另走完整 Linux CI。

上轮能力与人工验收见 [0.57.0](RELEASE_0.57.0.md) 和 [上线清单](LAUNCH_CHECKLIST.md)。
