# 守简 0.44.0 第十七轮自检

录音兜底转写此前只依赖供应商每次网络调用的独立超时。内联转写失败后若切换文件上传、再次识别，整轮可能持续过久并占用服务端云端并发名额。现在录音转写与聊天共用 `UPSTREAM_DEADLINE_MS` 的整轮期限；浏览器中途断开也取消上游。Gemini 的内联请求、上传开始、上传完成与文件识别均接收该取消信号。取得文件名后，即使识别被取消，仍会尽力发送独立的临时文件删除请求。

回归覆盖超时后容量恢复、浏览器断开取消，以及上传后取消仍发送删除请求。供应商侧删除成功率、上传过程断开时尚未取得文件名的临时文件留存，仍需真实账号和数据条款验收。

本地 `npm test` 237 / 237、Chromium / WebKit 及两组移动仿真 44 / 44 通过；固定 RAG 集 recall@4 与域外负例精度均为 100%，项目检查、空白符检查和生产依赖审计通过。
