# 守简 0.53.0 自动语音对话、会话清空与白话解卦

浏览器 `SpeechRecognition` 返回 `network` 时，自动语音对话现在切到 Web Audio 停顿检测、`MediaRecorder` 和 Gemini 整句转写。说完停顿约 850 ms 自动送问；无语音超时不上传，朗读期暂停收音。手动录音保留。实现借鉴本地 Cactus 的音频采集与 turn-taking 思路，但未复制其无许可证源码，也未声称使用 Google Cloud StreamingRecognize。

“另起一问”现明确保留聊天记录；“清空记录并重新开始”删除浏览器 `localStorage` 会话并重置当前卦。刷新后仍为空的浏览器回归已加。起卦卡片立即显示原问、上下卦转化成的白话观察角度；云端解说被要求先给有条件的现实判断，再解释经传依据。对“搬家合不合适”的真实 Gemini 请求能给出核对合同和预算的建议与引文，但模型仍可能使用过于确定的未来措辞，需持续审查，不能作为现实预测。

本机验证：253 个单元测试通过，桌面/移动 Chromium 与 WebKit 共 76 个页面用例通过；最后一次白话卦卡调整又分别通过四组浏览器的起卦页面回归。`npm run check`、固定 RAG 评测与生产依赖审计通过，审计为 0 个已知漏洞。真实 Chromium 加合成麦克风的端到端语音回环成功自动送问且音轨已结束，但“周易”误听成“中医”，停顿到送问约 8.3 秒。Windows Firefox 本机运行环境仍有故障；真实麦克风、噪声、扬声器回声、用户体验与低延迟指标尚未验收。远端 CI 结果须以本版提交为准。
