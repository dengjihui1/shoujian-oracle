# 0.55.0：门扉开场与页面重设计

首次进入页面显示中式双扇门，可点击“推门入境”立即进入，短暂停留后也会自动打开。动画只在当前标签页首次进入时播放；偏好减少动态效果时直接显示主页面。此标记与会话记录分开保存，开门不会清理问卦和聊天历史。

主页面改用深青、古金与朱砂的统一配色。桌面把墨衡人物和对话并列，手机端缩短人物场景，让输入框较早进入视野；状态、消息、输入与两个提问动作有明确层级。导出、导入和清除记录收进“记录与隐私”，仍可随时使用。起卦访谈、白话卦解、语音和经传引用的行为保持原链路。

验证：260 项单测与项目检查通过；桌面 Chromium、桌面 WebKit 和两组移动仿真的既有 76 项浏览器流程通过，另有真实 AudioWorklet 语音回环 1 项和门扉点击、自动打开及减少动态效果 3 项 Chromium 验证通过。其他浏览器项目中这 4 项按测试范围跳过。桌面 1440×900 与窄屏 390×844 的页面截图已人工检查。Firefox 本机启动仍受 `spawn UNKNOWN` 环境问题影响，以远端 CI 为准。
