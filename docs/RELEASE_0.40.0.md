# 守简 0.40.0 第十三轮自检

匿名来源级短窗口不能限制一个 Node 进程同时占用的云端请求数。现在聊天、转写和朗读共用可配置的进程级并发闸门，默认 16；超出时明确返回 503 `server_busy` 与 `Retry-After: 2`，不会发起新的供应商调用。结束后名额在 `finally` 中释放。健康检查与状态查询保持可用。

回归用一个未完成的聊天请求占满名额，确认朗读请求被拒绝且不会调用供应商；聊天结束后朗读恢复。该闸门限制单进程资源，不是多实例共享账单预算或付费账号额度。后续需要按真实供应商延迟、内存和目标峰值压测调整上限。

本地 `npm test` 230 / 230、Chromium / WebKit 及两组移动仿真 44 / 44 通过；固定 RAG 集 recall@4 与域外负例精度均为 100%，项目检查、空白符检查和生产依赖审计通过。
