# 守简 0.34.0 第七轮自检

本轮复查会话导入、来源展示与刷新恢复。过去导入文件可携带 `null` 来源条目；页面已经保存文件后，渲染来源时会抛错，并可能把不可渲染记录留在本机存储。仅有正确外壳、却没有会话内容的文件也会产生底层异常。

现在导入时要求会话消息列表存在，对来源条目做结构与长度约束；只保留当前冻结知识包所用的中文维基文库 HTTPS 链接。其他网址不会被呈现为“本答检索依据”。同样的清洗也适用于浏览器本机恢复。

新增单测和浏览器回归，覆盖异常来源导入、刷新后的可用性及外部网址过滤。浏览器测试的初始化清理改为每个测试上下文只执行一次，使刷新测试真正检验本机记忆。本地 `npm test` 220 / 220、Chromium / WebKit 及两组移动仿真 44 / 44 通过；固定 RAG 集 recall@4 与域外负例精度均为 100%，项目检查、空白符检查和生产依赖审计通过。CI 结果仍须按最终提交核对。

此轮验证的是本地文件处理与页面恢复；真人对引用语义是否贴合经文的评审仍未完成。
