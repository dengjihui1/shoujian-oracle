# 守简 0.46.0 第十九轮自检

从前端模块重新审查时发现，服务端与供应商流解析已有单块、单事件和整轮回答上限，但浏览器 SSE 解析尚无独立上限。现在三项限制使用同一份 `src/stream-limits.js` 常量；浏览器在解析超限数据时停止读取并取消响应流，累计回答过长时也不会先交给页面回调。

回归使用异常网络块、未终止的过大事件与过长回答，确认浏览器拒绝并取消流。此前正常的 CRLF 分块、流式替换及完成事件继续通过。

本地 `npm test` 242 / 242、Chromium / WebKit 及两组移动仿真 44 / 44 通过；固定 RAG 集 recall@4 与域外负例精度均为 100%，项目检查、空白符检查和生产依赖审计通过。
