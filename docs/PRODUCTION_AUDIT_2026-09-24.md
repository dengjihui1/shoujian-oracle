# 守简生产审计台账

目标：逐模块核对代码、自动测试、部署配置和真实运行证据。当前仓库是匿名开源教学组件；“生产可发布”需要先定义公开演示、企业内网或付费服务的目标，再按目标完成外部验收。下表的“待验收”不能写成已通过。

| 轮次 | 模块与当前证据 | 本轮判断与后续门槛 |
| --- | --- | --- |
| 1 | HTTP 入口：`server/index.mjs` 有请求体限制、静态资源白名单、安全响应头；0.39.0 加流式响应上界，0.41.0 加显式接收期限 | 仍需真实代理链路的慢连接、超时和峰值并发压测 |
| 2 | 代理与 TLS：`deploy/Caddyfile`、Compose 和 CI 有配置校验 | 实际域名、证书链、SSE 透传、外部请求头边界待真实部署验证 |
| 3 | 匿名限流：Redis Lua 原子短窗口、健康探针失败关闭；0.40.0 加进程级云端并发上限 | 每 IP 40 次/分钟与每实例并发闸门不是账号权益或全局成本上限；公开服务仍须加账号与账单预算 |
| 4 | 云端模型：Gemini 与兼容供应商有超时、失败回退和熔断；0.39.0 加输出边界，0.43.0 加聊天总期限，0.45.0 修复全部熔断时仍重试主供应商 | 仍需真实额度、重试成本、供应商 SLA 与区域可用性验证 |
| 5 | RAG：冻结 64 卦知识包、检索固定集与引用 ID 白名单 | 固定集召回不等于答案正确；需逐条人工核对引用语义并审查提示注入 |
| 6 | 起卦：六爻纯函数与服务端重算 | 测试覆盖确定性，但“占卜准确”不属于可验证产品承诺 |
| 7 | 语音输入：浏览器识别优先、短录音兜底与取消路径；0.44.0 给录音转写链路加总期限并传递断开信号 | 真实麦克风、安静/噪声、权限拒绝和上游临时文件删除须设备与供应商验收 |
| 8 | 语音输出：句级预取、取消、缓存和失败降级 | 真实首声 P50/P95、扬声器回声、音色和成本尚无生产样本 |
| 9 | 页面与会话：本机 24 条已完成消息、导入验证与浏览器回归 | 仍需无障碍、低端设备、长会话及真实用户任务测试；本机存储由设备使用者管理 |
| 10 | 隐私与日志：请求 ID、脱敏结构化日志、不建服务端用户档案；0.42.0 记录中途断开的请求 | 仍需生产日志留存政策、供应商数据条款、删除请求流程和隐私告知 |
| 11 | 构建与交付：CI 跑单测、五浏览器项目、RAG、依赖审计、容器/Redis/Caddy smoke | 还需发布冻结、环境差异、回滚演练、镜像来源与供应链策略 |
| 12 | 运行与恢复：存活/就绪探针、容器自动重启、部署文档 | 还需告警、错误预算、故障演练、负载测试、真实供应商账单阈值 |

参考基线： [OWASP DoS Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Denial_of_Service_Cheat_Sheet.html)、[Node.js Security Best Practices](https://nodejs.org/en/learn/getting-started/security-best-practices)、[Caddy reverse_proxy 文档](https://caddyserver.com/docs/caddyfile/directives/reverse_proxy)。这些是审计参考；本表只记录已核对的仓库事实和仍需完成的验收，不声称通过 OWASP 认证。
