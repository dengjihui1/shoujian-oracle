# 300 元以内的小规模网站验证方案

更新：2026-09-27。用户已确认独立网站／手机网页，人民币月预算不超过 300 元。本轮只推荐一套方案：**单机 Node + Caddy + 私网 Redis，优先文字和浏览器语音，以现有人物素材做本地动效，受邀逐步放量。** 不购买逐轮生成视频的数字人服务，不加数据库、向量数据库或额外供应商订阅。

下列人民币金额是预算分配，不包含开发劳务。2026-09-27 已恢复本机代理并核对 [Google 官方价格](https://ai.google.dev/gemini-api/docs/pricing#gemini-3.1-flash-lite)：Gemini 3.1 Flash-Lite 标准付费档每百万文本输入 token 0.25 美元、输出（含思考）1.50 美元。真实普通及流式请求均成功。购买日仍须核对价格、地区、税费、汇率及账号配额。

| 监控与日志 | 0 元新增订阅 | 复用平台告警与已有探针；核对免费监控限制，配置日志轮转 |

购买门槛：若主机的真实续费与流量使固定开支超过 90 元/月，先调整部署规格或供应商，再计算 API 额度；不要签长期方案后指望免费 API 抵消超支。最终供应商由实际地域可用性、账单和设备测量决定。

## 2. 沿用现有架构，先把每轮成本测清

| 能力 | 推荐路径 | 仓库状态 / 验收条件 |
| --- | --- | --- |
| 文字与经传问答 | 一个已核验的小模型，固定本地经传检索；只有明确失败时走受控回退 | 已有 fast/grounded 路由与回退；示例模型 ID 不是实时可用性证明，不新增多供应商费用 |
| 随机排卦 | 已有本地纯函数及服务端复算 | 不为排卦额外购买 API；问题、生辰与随机结果的边界按测试验证 |
| 生辰参照 | 已用 `lunar-javascript` 1.7.7（MIT）本机排盘，支持公历/农历闰月、时刻未知与交界提示 | 日期/时刻只留页内存，刷新清除；单独同意后仅把四柱符号带入 AI。没有八字古籍库，只解释历法术语，不作命运精算，不改变随机六爻 |
| 人物真实感 | 现有资产、呼吸/眨眼/倾听动作及随实际音频变化的嘴部，手机减少动画降级 | 属于浏览器渲染，基本不增加每轮云调用；需真实设备测帧率/电量，不能称照片级实时数字人 |
| 日常朗读 | 浏览器 TTS 默认选择；文字始终可继续输入 | 浏览器音色随设备变化；“不产生本项目 TTS API 账单”不等于保证离线或统一音质 |
| 语音输入 | 用户按需开启浏览器识别，失败回到文字 | 浏览器识别可使用第三方在线服务；生产 `PAID_AUDIO_ENABLED=false` 会阻止 Gemini 录音兜底，不能把它宣传为已开启 |
| Google 流式 STT / 云 TTS | 初期关闭，只有完成预算/设备验收后才考虑启用 | 已有服务端总开关 `PAID_AUDIO_ENABLED=false`，同时拦截 Gemini 和 Google 付费音频，包括 STT WebSocket；供应商单独开关不能绕过它 |

现有 `CachedSpeechService` 能复用相同文字/声音的生成音频，默认 30 分钟内存缓存；个性化回答命中率未知，不用理论缓存命中率作为省钱承诺。用户停止朗读后，已发给上游的请求仍可能计费，必须以供应商使用记录核对。

## 3. 已实现的保护与部署核验

以下已经写入仓库，剩余工作是把正确配置部署到真实服务器并验收，无需用户另外开发闸门：

```dotenv
NODE_ENV=production
MONTHLY_BUDGET_UNITS=1000
BUDGET_TEXT_UNITS=1
BUDGET_AUDIO_UNITS=5
PAID_AUDIO_ENABLED=false
```

字段是 `BUDGET_TEXT_UNITS`，不是 `BUDGET_CHAT_UNITS`。必须从本次生产示例同步；遗漏 `MONTHLY_BUDGET_UNITS` 或填 0 会关闭该保护。

1. **月度全局准入已经实现。** 以上海自然月计数，文字一次预占 1 单位、启用时音频一次 5 单位，同一 Redis 的各实例共享原子计数。失败、接口内部本地回复、语音缓存命中也不退款；达到上限返回 `monthly_budget_exhausted`，存储故障则拒绝请求。它是请求数量控制，不是实际费用账本。
2. **生产计数可持久化。** Compose 使用 `redis_data` 卷，Redis AOF `appendfsync always` 和 `noeviction`。生产开启额度却没有共享 Redis 时拒绝启动。部署者须保留同一数据库及持久卷，不得通过删卷、清库或换库重置用量。`noeviction` 内存不足时可能拒绝写入，应修复容量，不能关闭保护继续放量。
3. **付费音频已真正关闭。** `PAID_AUDIO_ENABLED=false` 在服务端阻断 TTS、短录音转写及 STT WebSocket，包括 Gemini 回退；浏览器 TTS/识别仍可按设备能力使用。以后开启付费音频必须重新核价与验收。
4. **Gemini 输出与思考已统一。** 普通和 SSE 请求均设置最多 2048 输出 token、低思考。真实账号仍须验证模型接受参数；这不是人民币限额，也不能抹去输入、思考、失败重试、模型回退与引用修复的潜在成本。
5. **人民币费用仍以账单核验。** 当前没有按真实价格自动结算人民币的精确账本；账号持有人按供应商用量/账单核对输入输出、模型、重试与税费，再调整单位额度。预算提醒也不是供应商硬停费保证，不承诺严格 300 元绝对封顶。不要为核价收集问题、生辰或录音正文。

部署时另核验主模型和回退模型价格；不需要的回退可使用已有的空列表配置停用，不能盲目继承旧示例里的型号。先用预发布独立 Redis 数据库做小额度耗尽和重启保持测试，再启用正式生产数据库。

建议起步参数：单 Node 实例 `MAX_CONCURRENT_UPSTREAM=4`，保留 Redis 限流，先用现有 `RATE_LIMIT_MAX=40` / 60 秒观察正常使用。每句话可能触发多个 TTS 请求，多人同一 Wi-Fi 也可能共用来源，不能机械地把请求数当作聊天轮数。配额调整以正常会话和滥用测试为准。

费用分级动作（**待落实并演练**）：

| 阈值 | 负责人动作 | 必须验证 |
| --- | --- | --- |
| API 日支出约 4 元或明显异常 | 暂停新邀请，查实际模型、重试与语音用量；当日小额测试结束 | 不能仅清空日志或刷新账单页面后继续放量 |
| API 月累计 80 元 | 复核剩余天数和预测；维持文字优先 | 供应商账单可能延迟，使用本地用量估算加预留 |
| API 月累计 100 元 | 停用非必要付费语音，复核文字与转写预算 | “停用”要阻止服务端调用，不只关闭前端开关 |
| API 月累计 130 元，或全部费用预计达到 220 元 | 关闭新增付费请求，转本地体验；人工复核后才能动用储备 | 超限请求应无新上游调用；不把可能已计费的在途请求当作零费用 |

初期保持小范围受邀验证，定期看账单；月度单位闸门已经提供服务端数量上限，值守和网关访问保护进一步降低额度被陌生人耗尽的风险。需要提前停用时，在实际供应商禁用调用权限或在受控网关拒绝付费 API；如切换本地模式，移除服务端 Gemini 配置后重建 app 并验证 `cloud:false`。不要用 `MONTHLY_BUDGET_UNITS=0` 停服，因为 0 表示关闭保护、允许请求；不要删除 Redis 卷。核对停用后没有新增计费调用。

## 4. 用小样本选择性能配置

阶段一：3–5 位受邀者，在真实 Android Chrome 与 iPhone Safari 各测文字/语音，先收集约 50 轮文字、30 轮实际开启的语音。先不买更昂贵模型或人物渲染服务。

阶段二：至少完成 7 天受控验证，得到实际每轮成本后，最多扩大到约 20 位邀请用户，同时保留默认每月 1000 单位。人数不是额度，每人可用次数受总量和实际消耗共同限制，不承诺 20 人可无限聊天。

| 指标 | 起步验收目标 | 处理 |
| --- | --- | --- |
| 文字首字 | P50 ≤ 2.5 秒，P95 ≤ 5 秒 | 先检查网络、提示长度、模型与回退次数，再换更贵模型 |
| 浏览器语音首声 | P50 ≤ 3 秒，P95 ≤ 6 秒 | 与云 TTS 分开统计；不达标仍可开放文字 |
| ASR 定稿 | P50 ≤ 0.8 秒，P95 ≤ 1.5 秒 | 流式识别与整句转写分开，不用混合平均掩盖延迟 |
| 交互正确性 | 零重复发送、零停麦失败、零旧回答复活、零文字锁死 | 任一出现先停相应模式、定位和重测 |
| 页面与人物 | 目标手机输入/滚动可用、无横向遮挡；减少动画正常 | 先减少动画层和动效，避免增加 GPU/视频服务成本 |

以上是目标，不是已测成绩。保留设备/网络/日期、成功率、延迟样本和去内容化使用量；遵循 `DEVICE_ACCEPTANCE.md` 的噪声与回声项目。

### 计算每轮预算

```text
文字费用 = 输入计费单位 × 输入单价 + 输出计费单位 × 输出单价
识别费用 = 实际计费音频时长 × 对应接口单价（包含最低计费单位）
朗读费用 = 对应产品实际计费字符/音频单位 × 单价
总 API 费用 = 以上费用 + 重试/回退/修复 + 税费与汇率差
可放量轮数 = 剩余 API 预算 ÷ 实测每轮费用的保守值
```

例如，20 人 × 每人每天 1 轮 × 30 天 = 600 轮，可以作为默认 1000 个文字准入单位内的计划起点。失败等也消耗单位，不能把 1000 单位宣传为保证成功的 1000 轮。若给 1000 个单位分配 100 元，倒推的预算要求是平均每单位不超过 0.10 元；这是成本要求，不是模型报价。语音占比、上下文、重试、税费及单位内多次上游请求均需纳入实测。
