# 0.57.0：本机生辰参照、人物表现与受控网站试用

目标：独立网站和手机网页、月预算 300 元以内的小规模验证。主实现与 Astra 独立审查共同完成；本版本未代替账号持有人购买或部署正式站点。

## 已完成

- 可选公历/农历闰月四柱排盘，成熟 MIT 历法引擎按需加载；北京时间、午夜换日、未知时刻和节气边界有明确说明。
- 生日和时刻仅留页面内存，刷新清除；单独同意后仅发送四柱符号。修改输入立即撤销旧盘和同意，服务端白名单验证并丢弃其他字段。
- 生辰与随机起卦独立，显示术语白话解释与表层五行计数；当前无八字古籍库，不提供完整命理分析。
- 扩大写实人物拱形半身构图，恢复呼吸、眨眼、倾听和点头，嘴部由实际播放状态驱动；减少动画偏好可停用动作。保留中式门扉、山水月色、印章与简化主操作。
- Redis 原子月度额度、AOF 持久化、故障关闭、HTTP/STT 共用额度；默认停用付费语音，文字模型最多 2048 输出 token、低思考，生产示例关闭跨模型升级回退。
- 提供 Caddy 受邀口令入口、Compose 叠加配置、配置预检查与真实 Redis 并发/重启 smoke，已纳入 CI；密钥和邀请环境文件排除出 Git。
- Astra 最终审查发现付费语音关闭后仍提示录音兜底，已改为明确回到文字并补浏览器回归；修正白话解卦重复“先”字。
- [人工上线清单](LAUNCH_CHECKLIST.md)、[预算与性能方案](COST_PERFORMANCE_PLAN.md)、[受邀部署](INVITE_DEPLOYMENT.md) 已给出操作命令及通过标准。

## 交付边界

Firefox 在本机的既有启动限制、Docker 引擎未运行所涉及的检查由 Linux CI 覆盖；以本次 SHA 的实际 CI 结果为准。Google Cloud 流式识别、真人麦克风、真机音色、域名证书、真实 Redis 部署持久性和账单待清单验收。月度额度控制请求量，不能保证人民币绝对封顶。人物为现有写实素材的浏览器动画，并非实时视频数字人。

发布后先受邀试用；只有适用清单全部通过，才判断实际开放范围，不能凭自动测试保证平台或监管审批。
