# 守简 0.42.0 第十五轮自检

服务端此前只在响应 `finish` 时记录 HTTP 请求。浏览器停止或离开流式回答时，连接在 `close` 结束，这一轮可能从日志中消失。现在未正常完成的连接记录 `http_request_aborted`、内部状态 499、请求 ID、路径与耗时。正常结束仍只记录一次；日志不记录问题、回答或录音。回归覆盖断开浏览器后供应商取消及中断日志。

该修复提高生产排障可见性；告警、日志留存周期和外部监控仍待实际部署配置。

本地 `npm test` 231 / 231、Chromium / WebKit 及两组移动仿真 44 / 44 通过；固定 RAG 集 recall@4 与域外负例精度均为 100%，项目检查、空白符检查和生产依赖审计通过。
